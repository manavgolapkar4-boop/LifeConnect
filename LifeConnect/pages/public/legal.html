Privacy, Terms & Disclaimer

Plain-language notices for this academic project.

Privacy

LifeConnect is a student project (TYIT Semester 5). No part of this site collects, sells, or shares real personal data with any third party, because no real personal data should ever be entered here.

  • Sign-up and login (Phase 3) store your name, email, phone and a securely hashed password in a local JSON file on the project's own demo backend — never in plain text, and never shared externally.
  • Donor, request and hospital information shown throughout the site is fictional demo data (see js/mock-data.js), clearly not real people.
  • Your information should only ever be shared for legitimate medical/emergency purposes — this project does not implement real sharing with hospitals or third parties.

Terms

By using this demo, you agree that:

  • LifeConnect is an academic prototype, not a commercial or medical service.
  • Accounts, donor profiles, hospital listings and blood requests on this site may be fictional or created for testing and can be reset at any time.
  • You will not enter real sensitive personal or medical information into this demo.

Disclaimer

Always contact appropriate emergency medical services for life-threatening situations. LifeConnect does not replace professional medical or emergency services.

This project does not verify real-time hospital blood availability, real-time donor availability, or medical eligibility to donate. Every "verification," "availability," and "match score" shown is demo data or a frontend-only placeholder, not a live or medically validated result.
